# User Stories

Format: As a \[type of user], I want \[goal], so that \[reason or benefit].

1. As a business manager, I want to view customer sentiment trends, so that I can make informed decisions to improve products and services.
2. As a marketer, I want customer feedback to be automatically classified as positive, negative, or neutral, so that I can quickly understand customer opinions without manually reviewing every comment.
3. As a customer service representative, I want to identify negative feedback quickly, so that I can address customer issues and improve customer satisfaction.
