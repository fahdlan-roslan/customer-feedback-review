# Requirements

## Functional requirements (what the system must DO)

1. The system shall allow users to upload customer feedback datasets for analysis.
2. The system shall clean and prepare the feedback data by removing irrelevant information and duplicate entries.
3. The system shall analyze customer feedback using a machine learning model.
4. The system shall determine whether each feedback entry is positive, negative, or neutral.
5. The system shall generate a report that summarizes customer sentiment and highlights key findings.

## Non-functional requirements (how the system must PERFORM)

1. The system shall process and classify customer feedback within 2 seconds per submitted record.
2. The system shall achieve at least 80% accuracy in sentiment classification when tested with a labelled dataset.
3. The system shall provide results in a clear and easy to understand format.
